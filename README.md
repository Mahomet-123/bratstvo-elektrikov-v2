# Братство Электриков v2

PWA-приложение для электромонтажной бригады: расчёт по прайсу, объекты, журнал дней,
закупки с фото накладных, офлайн-очередь отправки и PDF-отчёты клиентам.

Работает с телефона, устанавливается на экран «Домой», продолжает работать без сети.

## Что уже работает

- **Вход** по имени и коду доступа. Руководитель — `Руководитель` / `0000` (сменить сразу).
- **51 профиль**: руководитель и мастера 1…50. Коды мастеров выдаёт руководитель.
- **Прайс**: 204 позиции в 8 разделах — 194 работы, 6 коэффициентов, 2 наценки, 2 примечания.
- **Профиль**: смена своего кода, состояние отправки, выход.
- **Офлайн**: сервис-воркер кэширует оболочку, приложение открывается без сети.
- **Журнал посещений**: кто и когда заходил, что делал.

## Структура репозитория

```
backend/            бэкенд Apps Script — модули СТРОГО отдельными файлами
  Config.gs         настройки и схема таблицы
  Utils.gs          общие утилиты
  Sheets.gs         низкоуровневая работа с таблицей и блоками листов
  Sessions.gs       сессии входа
  Users.gs          профили, коды, роли
  Prices.gs         прайс
  Visits.gs         журнал посещений
  Statuses.gs       состояние очереди отправки
  DriveFiles.gs     папки и файлы Google Диска
  Router.gs         маршруты API
  Code.gs           точка входа веб-приложения
  Seed.gs           инициализация таблицы
  SeedData.gs       данные прайса (генерируется автоматически)
  seed/price.json   прайс, разобранный из PDF

public/             фронтенд PWA — статика без сборки
  index.html        оболочка
  manifest.webmanifest
  sw.js             сервис-воркер (офлайн)
  css/              base, components, layout
  js/config.js      адрес API и настройки
  js/core/          dom, format, icons, logger, modal, router, store, styles, toast
  js/api/           apiClient, endpoints
  js/components/    Login, AppShell, Profile, SyncIndicator, …

scripts/            вспомогательные скрипты разработки
  parse-price-pdf.py   разбор прайса из PDF
  build-seed-data.js   генерация SeedData.gs
  check-syntax.js      проверка синтаксиса всех модулей
  api.js               вызов API из консоли
  serve.js             локальный сервер для проверки
```

## Команды

```bash
npm install                 # зависимости разработки

npm run seed                # разобрать прайс из PDF в backend/seed/price.json
npm run seed:data           # собрать backend/SeedData.gs из price.json
npm run build               # обе команды подряд

npm run gas:push            # залить бэкенд в Apps Script
npm run gas:deploy          # опубликовать новую версию веб-приложения
npm run gas:open            # открыть проект в редакторе Apps Script

npm run check               # проверить синтаксис всех модулей
npm run serve               # локальный сервер на http://localhost:4173
```

Заливка бэкенда доступна и из каталога `backend`: `cd backend && npm run gas:push`.

## Архитектура

- **Модульность обязательна.** Один файл — одна ответственность. Склейка модулей в один
  файл запрещена: Apps Script сам загружает `.gs` файлы по отдельности, фронтенд использует
  ES-модули.
- **БЭМ** в разметке и CSS: `.block__element--modifier`.
- **Комментарии и интерфейс — на русском.**
- **Fallback обязателен**: любая сетевая операция имеет понятный отказ, данные кэшируются
  локально, ошибки не роняют приложение.

## Ограничения Google

- ~90 минут работы скриптов в сутки.
- 15 ГБ диска — фото накладных сжимаются на телефоне до ~300 КБ в WebP и отправляются по одному.
